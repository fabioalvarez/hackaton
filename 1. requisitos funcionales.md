# Diseño arquitectónico — Nodo Ruta

Despliegue y recuperación de un servicio de consulta de entregas en contenedores.

## 1. Requisitos funcionales (historias de usuario)

**Criterio:** un requisito es funcional solo si expresa una necesidad de negocio, se verifica con **una prueba concreta** (estado + entrada → salida), es atómico, independiente de la implementación y sin ambigüedad.

**Actores:** Operador (equipo de operaciones), Responsable técnico, Coordinador logístico.

### Consulta

**RF-01 · Consultar pedidos**
- Como **operador**,
- quiero consultar la lista de pedidos,
- para conocer el estado de las entregas.
- *Prueba:* Dado que hay 6 pedidos cargados, cuando se solicitan los pedidos, entonces el servicio responde con los 6 pedidos.

**RF-02 · Ver la versión de los datos**
- Como **responsable técnico**,
- quiero que la consulta de pedidos incluya el identificador de versión de los datos,
- para comprobar qué versión de datos está sirviendo el sistema.
- *Prueba:* Dado que los datos tienen la versión V, cuando se solicitan los pedidos, entonces la respuesta incluye la versión V.

**RF-03 · Acceder a la página de inicio**
- Como **operador**,
- quiero abrir la página de inicio del servicio,
- para confirmar que estoy en el servicio correcto.
- *Prueba:* Dado que el servicio está activo, cuando se solicita la página de inicio, entonces el servicio la muestra.

### Salud e identificación de instancia

**RF-04 · Consultar la salud del servicio**
- Como **coordinador logístico**,
- quiero consultar el estado de salud del servicio,
- para conocer si el servicio está disponible.
- *Prueba:* Dado que el servicio está disponible, cuando se consulta su salud, entonces el servicio informa que está "ok".

**RF-05 · Identificar la instancia que atendió una solicitud**
- Como **responsable técnico**,
- quiero que cada respuesta indique el identificador de la instancia que la atendió,
- para saber qué instancia respondió.
- *Prueba:* Dado que la instancia A está activa, cuando A atiende una solicitud, entonces la respuesta contiene el identificador de A.
